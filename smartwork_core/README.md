# smartwork_core

Core logic for [SmartWork](https://pub.dev/packages/smartwork_cli) — Flutter
project generation, architecture scaffolding, feature generation, and
Production Services.

This package is the shared engine behind `smartwork_cli` and the SmartWork
MCP server. It isn't meant to be depended on directly by application code —
install the CLI instead:

```bash
dart pub global activate smartwork_cli
```

SmartWork supports only the latest stable Flutter SDK. For using the API
directly, see [`example/example.dart`](example/example.dart).

Full documentation lives in the
[SmartWork repository](https://github.com/mskathirravan/smartwork_cli).
